# kot-cloud

#### Description
This project aims to build an enterprise-level backend scaffolding with Kotlin as the primary language. It is also a process of learning Kotlin.

#### Software Architecture
The project is dedicated to building a modern, high-performance microservices architecture with the following technology stack:

**Core Language**:
- [Kotlin](https://kotlinlang.org/) 2.3.0 - As the main development language, fully utilizing its null safety, extension functions, coroutines and other features to improve development efficiency and code quality

**Core Framework**:
- [Micronaut](https://micronaut.io/) - Chosen for its fast startup and low memory footprint, especially suitable for microservices and cloud-native applications, with significant performance advantages over Spring Boot

**Build Tool**:
- [Gradle](https://gradle.org/) - Using Kotlin DSL as the build script language, providing better IDE support and type safety

**Compilation Optimization**:
- [GraalVM](https://www.graalvm.org/) - Used to compile applications into native images, greatly reducing startup time and memory consumption, maximizing Kotlin's advantages

**ORM**: Hybrid approach

- [Micronaut Data](https://micronaut-projects.github.io/micronaut-data/latest/guide/) - For the data access layer, providing type-safe ORM capabilities

- [Exposed](https://github.com/JetBrains/Exposed) - For relational database access, providing a type-safe SQL builder

**Database**:

- [MariaDB](https://mariadb.org/) - For relational databases
