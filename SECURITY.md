## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

### How to Report

- Report the vulnerability via the project's issue tracker.

### What to Expect

- **Acknowledgement**: We will acknowledge receipt of your report within a reasonable timeframe.
- **Assessment**: The maintainers will investigate and assess the reported issue.
- **Updates**: You may receive periodic updates on the status of the investigation.

### Resolution

- If the vulnerability is confirmed, we will work on a fix and release a security update as appropriate.
- If the report is declined, an explanation will be provided.

We appreciate responsible disclosure and your efforts to help improve the security of this project.
